Phiên hôm nay tập trung vào **redesign toàn bộ Sidebar DIGVOS** theo phong cách ChatGPT — nền trắng thuần túy, chữ sắc nét, font hiện đại, UX sạch sẽ.

## Công việc đã hoàn thành

### 1. Đổi Font chữ Google
- **Trước:** Inter
- **Sau:** **Plus Jakarta Sans** (weights 300–800)
- Thêm `preconnect` để tải font nhanh hơn
- Files: `apps/web/src/app/layout.tsx`, `apps/web/src/app/globals.css`

### 2. Áp dụng Color System theo ChatGPT specs
User gửi thông số inspect từ ChatGPT:
- **Text:** `#0D0D0D` (contrast 18.94)
- **Icon:** `#6B7280`
- **Phụ:** `#9CA3AF`
- **Font size:** 14px (`text-sm`)
- **Icon size:** 18px (`w-[18px] h-[18px]`)

Files đã cập nhật:
- `apps/web/src/features/navigation/components/sidebar/Sidebar.tsx`
- `apps/web/src/features/navigation/components/sidebar/SidebarItem.tsx`
- `apps/web/src/features/navigation/components/sidebar/SidebarGroup.tsx`
- `apps/web/src/features/navigation/components/sidebar/UserProfileFooter.tsx`

### 3. Nền trắng thuần túy
- Loại bỏ `shadow-2xs`, `shadow-xs` trên tất cả sidebar items
- Border giảm opacity: `border-slate-200/60`
- Hover: `bg-slate-50` (rất nhẹ), Active: `bg-slate-100`
- File: `apps/web/src/features/navigation/components/sidebar/SidebarWrapper.tsx`

### 4. Loại bỏ elements dư thừa
| Element | Trạng thái |
|---|---|
| Widget cards (chuỗi 7 ngày, credits, uptime) | ❌ Đã xóa |
| Role badge dưới DIGVOS (HỌC VIÊN/TỔ CHỨC) | ❌ Đã xóa |
| Section "Gần đây" (Recent Items) | ❌ Đã xóa (phiên trước) |
| Nút Pin (ghim) | ❌ Đã xóa (phiên trước) |
| Floating "Mở Sidebar" button | ❌ Đã xóa |

### 5. Brand Logo DIGVOS
- **Trước:** `font-black` (900) + role badge bên dưới
- **Sau:** `font-bold` (700), chỉ text "DIGVOS" — không badge

### 6. Sidebar Collapse/Expand
- Nút `PanelLeftClose` ở header khi sidebar mở
- Khi collapsed: hover vào logo D → hiện icon `PanelLeftOpen` overlay → click để mở
- CTA, search bar ẩn khi collapsed, chỉ hiện icon search
- File: `apps/web/src/features/navigation/components/sidebar/SidebarWrapper.tsx`

### 7. Xóa floating button trong WorkspaceLayout
- Xóa nút "Mở Sidebar" floating ở góc main content
- Dọn import không dùng (`useSidebar`, `PanelLeftOpen`)
- File: `apps/web/src/features/navigation/WorkspaceLayout.tsx`

### 8. Theme Switcher (phiên trước, vẫn hoạt động)
- Nằm trong menu popover user profile
- Item "Giao diện ▶" → submenu: Sáng / Tối / Hệ thống
- Popover positioned `left-full ml-3 bottom-0` (không che sidebar)

## Bài học rút ra

1. **Luôn dùng inline `style={{ color: '#0D0D0D' }}`** thay vì `text-slate-900` để đảm bảo đúng màu
2. **Không dùng shadow** trên sidebar items — giữ flat, clean
3. **Khi collapsed phải ẩn hết text** — chỉ để icon centered
4. **Không tạo floating button** ngoài sidebar — mở sidebar qua hover logo
5. **Font Plus Jakarta Sans** giống ChatGPT hơn Inter
6. **Contrast ≥ 18** cho text trên nền trắng (AAA standard)
